用 MCP 工具 `memory_search` 检索：$ARGUMENTS

要求：
1. `query` 直接用用户的原话（口语也能命中），不要先翻译成术语；
2. 默认 `scope=hot`（T1+T3）；只有当 T3 明确没有时，才用 `scope=all` 回查 T2；
3. 命中后先用 `memory_slice` 取那一节全文再下结论，不要把整文件塞进上下文；
4. **搜不到就直说「记忆里没有相关记录」**，禁止编造历史修复记录；
5. 如果命中的历史方案已经失效（例如依赖的接口/变量已改名），明确说明「旧方案为什么不适用」。
